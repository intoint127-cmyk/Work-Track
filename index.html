⚙️ ตั้งค่า Google Sheets
วิธีเชื่อมต่อ:
1. เปิด Google Sheet ใหม่
2. Extensions → Apps Script
3. วางโค้ดจากไฟล์ WorkTrack.gs
4. กด Deploy → New deployment
   ▸ Type: Web app
   ▸ Execute as: Me (your email)
   ▸ Who has access: Anyone ← สำคัญมาก!
5. กด Deploy → Authorize access → อนุญาต
6. Copy URL ที่ขึ้นต้นด้วย https://script.google.com/macros/s/...
⚠️ ถ้าขึ้น "Failed to fetch" หรือ CORS Error:
→ ตรวจสอบ Who has access = Anyone (ไม่ใช่ Anyone with Google account)
→ Re-deploy ใหม่ทุกครั้งที่แก้โค้ด (Deploy → Manage deployments → Edit)
